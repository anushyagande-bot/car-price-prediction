# car-price-prediction
🚗 Car Price Prediction using Machine Learning
📌 Overview

This project predicts the selling price of a used car using Machine Learning. It analyzes features such as car year, present price, kilometers driven, fuel type, transmission type, seller type, and owner information to estimate the car's market value.

🎯 Objectives
Predict used car prices accurately.
Perform data preprocessing and feature engineering.
Train and evaluate a Machine Learning model.
Build an interactive web application using Streamlit.
🛠️ Technologies Used
Python
Pandas
NumPy
Scikit-learn
Joblib
Streamlit
📊 Dataset Features
Year
Present Price
Driven Kms
Fuel Type
Selling Type
Transmission
Owner
Selling Price (Target)
🤖 Model Used
Random Forest Regressor
📈 Result
Achieved an R² Score of approximately 0.96, indicating high prediction accuracy.
🚀 How to Run
pip install -r requirements.txt
python src/train.py
python src/predict.py
python -m streamlit run app.py
💡 Outcome

The project helps users estimate the selling price of a car based on its specifications and demonstrates the practical application of Machine Learning in price prediction.
